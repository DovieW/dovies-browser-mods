# YouTube playlist duration

Browser Mods shows the duration of the current desktop YouTube playlist in its toolbar popup. It reads the full playlist page or the sidebar for a video opened within a playlist. The card distinguishes a total from a subtotal, counts duplicate playlist positions separately, and reports entries with missing durations. An incomplete sidebar links to the full playlist page.

The playlist-duration feature owns URL recognition, page reading, and the popup card. The existing Media switch controls availability. Opening the toolbar popup on a playlist uses existing `activeTab` access for one read in the tab’s isolated world. The read sends only aggregate counts and duration back to the popup. The feature adds no manifest permissions, API keys, network requests of its own, stored playlist data, or scripts that run on page load. [Chrome activeTab documentation](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

For a partial playlist page, the user can ask YouTube to load more through its normal scroll behavior. Browser Mods observes the relevant DOM only during that attempt and restores the original scroll position unless the user interacts or changes pages. Attempts are limited to 50 batches and 15 seconds. Failed or incomplete loading keeps the subtotal visible. YouTube’s DOM can change, so unfamiliar layouts fail visibly instead of reporting a zero-duration total. When a recognizable playlist count is available, it controls completeness even if YouTube keeps a continuation marker on the page.

The packaged browser fixture covers duplicate entries, unrelated videos, missing durations, a watch sidebar, lazy loading, and scroll restoration. It supplies YouTube access in a disposable manifest when opening the popup as a test page. A normal toolbar click grants the packaged extension access through the existing `activeTab` permission.

Live checks in a disposable Chromium profile found 54 readable videos on a public playlist and 400 on a second playlist after loading three additional batches. The longer run restored scroll to the top. On the regular popup benchmark, 15 samples each on Chromium 153, Node 26, and an Intel Core Ultra 9 285H gave a warm median of 84.5 ms before and 95.7 ms after, with warm P95 of 121.7 ms before and 108.3 ms after. Neither changed by both 20% and 20 ms. The benchmark measures popup startup away from YouTube. Playlist work runs only while using the card.
